# AGENTS.md — DELIVERY

Developer mode: **Brief → Spec → RUN → Code → Persistence**. Follow `delivery/AGENT_GUIDE.md`.

- Starts from a Refined Story, an analysis artifact, an original story or a direct request. A Refined Story is never required. Brief is always created here.
- After Brief and Spec exist, `delivery/` is the source of truth; go back to `analysis/` only to resolve ambiguity or reconcile.
- Never execute without a RUN; never write code before the strategy is in the RUN and approved; never expand scope beyond the Spec; analysis outputs never authorize execution by themselves.
